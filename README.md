# CX Pulse UAE
**Bilingual Customer Experience & Administrative Operations Platform**

CX Pulse UAE is a portfolio project designed to demonstrate practical thinking in customer service, administrative coordination, complaint handling, operational reporting and bilingual user experience.

## Current build: v0.1 — interactive front-end prototype
- Executive overview dashboard with sample KPIs and charts.
- Case management table with search.
- Create a customer case in the browser demo.
- English / Arabic language switch with RTL layout.
- CSV export for demonstration cases.
- Responsive desktop and mobile layouts.

## Important scope and data notes
- KPI figures and preloaded records are illustrative sample data, not real business performance.
- Newly created cases exist only in the current browser session; no backend or cloud database is connected yet.
- Do not enter real customer, banking, identity or other confidential information.
- AI assistance, authentication, role-based access, persistent database storage, audit logs and production deployment are planned but are not implemented in this version.

## Planned roadmap
1. UX and accessibility review; validate all bilingual labels and flows.
2. Add secure authentication and role-based permissions.
3. Implement Cloudflare Worker API and D1 schema with input validation.
4. Add audit trail, SLA rules and operational reporting.
5. Add AI-assisted categorisation and response drafting only after privacy and security review.
6. Deploy, test and document the live system.

## Run locally
Open `index.html` in a modern browser. No build step is required for this prototype.

## Portfolio context
This project is intended to complement practical experience in customer service management, administration, coordination and visual design. It is a demonstration product, not an affiliated bank or financial institution.
